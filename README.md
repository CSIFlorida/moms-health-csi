# Mom's Health CSI 💛

**Plan de ejercicios mamá María del Carmen en Ramiriquí, CSI app**

Aplicación sencilla para que mamá siga sus ejercicios diarios, uno cada hora y media, con instrucciones en letra grande, lectura en voz alta y mensajes de ánimo al terminar cada uno.

- **Abrir la app:** https://csiflorida.github.io/moms-health-csi/
- **Recordatorios:** abra `recordatorios-ejercicios-mama.ics` en el celular para agregar las 9 alarmas diarias al calendario.

> Ejercicios suaves y generales. Consulte con su médico o fisioterapeuta antes de empezar, especialmente después de cirugía de columna.
